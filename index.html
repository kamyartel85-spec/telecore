ساختار ذخیره‌سازی داده و تنظیمات Railway

تمام سشن‌ها، پایگاه‌داده و لاگ‌ها در یک مسیر متمرکز ذخیره می‌شوند تا به راحتی به Volume ریلوی متصل شوند

ساختار دایرکتوری متمرکز (Railway Volume Target)

با متصل کردن یک ولوم در ریلوی به مسیر /app/data یا /data، تمام فایل‌های زیر در جابه‌جایی سرورها پایدار خواهند ماند:

📁 /data (مسیر ولوم اصلی در ریلوی)
├── 📁 sessions/ # فایل‌های Session و اعتبارسنجی Telethon/Pyrogram
├── 📁 logs/ # آرشیو لاگ‌های عملیات‌ها و خطایابی
├── 📁 config/ # تنظیمات کاربری، کلیدهای API و پراکسی
└── 📄 database.sqlite # دیتابیس SQLite ذخیره کاربران، وظایف و آمار
وضعیت پوشه لوکال: آماده و دارای مجوز نوشتن
مسیر ولوم: /app/data

راهنمای دیپلوی روی Railway با دامنه دلخواه

  1. مرحله ۱: پروژه را در گیتهاب شخصی خود پوش (Push) کنید.
  2. مرحله ۲: در پنل Railway گزینه New Project -> Deploy from GitHub repo را بزنید.
  3. مرحله ۳ (بسیار مهم): روی سرویس کلیک کنید، تب Volume را باز کنید و یک Volume جدید با مسیر Mount Path: /app/data ایجاد کنید.
  4. مرحله ۴ (دامنه رایگان): در تب Settings -> Networking روی Generate Domain کلیک کنید.
💡 فایل‌های Dockerfile و railway.json برای اتصال خودکار پورت و ولوم داخل همین پروژه قرار دارند.
