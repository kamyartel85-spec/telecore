# TeleCore // پنل جامع مدیریت اکانت‌های تلگرام

یک پنل تحت وب با تم سایبرپانک، کرمی و روشن برای مدیریت اکانت‌های تلگرام، دریافت کدهای ورود (OTP)، انجام عملیات‌های گروهی (عضویت در کانال، لایک/ری‌اکشن، شرکت در نظرسنجی، استارت ربات)، مدیریت پیام‌های خصوصی و زمان‌بندی پیام‌های خودکار (Self-Bot).

---

## 📁 ساختار پوشه متمرکز جهت اتصال ولوم ریلوی (Railway Volume)

تمامی اطلاعات حساس و تغییرپذیر داخل یک مسیر ریشه به نام `data/` قرار می‌گیرند تا در جابه‌جایی یا ری‌استارت سرورهای ابری حفظ شوند:

```text
data/
├── sessions/          # فایل‌های سشن و احراز هویت تلگرام
├── logs/              # فایل‌های لاگ و گزارش عملکرد
├── config/            # تنظیمات اختصاصی، کلیدها و پراکسی‌ها
└── database.sqlite    # دیتابیس کاربران، سشن‌ها، آمار و تسک‌های زمان‌بندی
```

## 🚀 نحوه دیپلوی در Railway (با دامنه رایگان)

1. پوشه پروژه را در ریپازیتوری GitHub خود آپلود کنید.
2. وارد پنل [Railway.app](https://railway.app) شوید و گزینه **New Project -> Deploy from GitHub repo** را انتخاب کنید.
3. **تنظیم ولوم پایدار (بسیار مهم):**
   * روی سرویس ایجاد شده کلیک کنید.
   * به تب **Volume** بروید و روی **Add Volume** بزنید.
   * مسیر **Mount Path** را برابر با `/app/data` قرار دهید.
4. **دریافت دامنه رایگان:**
   * به تب **Settings -> Networking** بروید.
   * روی دکمه **Generate Domain** کلیک کنید تا یک آدرس اینترنتی رایگان (مانند `telecore.up.railway.app`) به شما اختصاص داده شود.
